# Volatility Clustering in Crypto and Traditional Markets: Machine-Learning Perspective
This repository contains the code to accompany my MSc Data Science and Analytics dissertation at Cardiff University.

The notebook analyses volatility clustering and uses GARCH, EGARCH, FIGARCH, XGBoost, LSTM and GARCH-LSTM for volatility forecasting across three cryptocurrencies and three traditional markets using data from 2018-2025.

Cryptocurrencies: Bitcoin, Ethereum, XRP

Traditional markets: S&P 500, FTSE 100, BSE SENSEX

MAE and RMSE are used for forecast evaluation with Diebold-Mariano tests to compare selected models within each market.

## Running the code
Open 'dissertation_code.ipynb' in Google Colab and run cells from top to bottom.
Note that model training can take several hours.
